# What CLARK learns from — the published work behind the rules

CLARK is built on published scholarship as well as on its maintainer's practice. This page lists the published sources whose ideas shaped a rule, a skill, or a document, with one line on what was taken and where it lives. It is a point-and-cite record, not a reproduction: read the originals. Listing a work implies no endorsement of CLARK by its authors. Software and services CLARK consumes are credited in the README; the reading lists inside each [field guide](../field-guides/README.md) belong to that guide's curator.

**How a source gets here.** A row is added in the same commit that places the idea, with the citation resolved at the time of writing. Criteria modules follow a stricter rule — publisher- and journal-provided reviewer material only — and cite their sources inside the module itself.
